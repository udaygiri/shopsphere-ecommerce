# Screenshots Directory

Save your 2–4 application screenshots here with the following filenames:
1. `storefront.png` — Storefront view showing products, category circles, search bar, and price range filters.
2. `cart-wishlist.png` — Wishlist view or Shopping Cart drawer showing items and price breakdown.
3. `razorpay-checkout.png` — Checkout screen with Razorpay test mode payment modal active.
4. `admin-dashboard.png` — Admin Dashboard showing platform revenue analytics cards and global orders list.

These images are automatically linked in `README.md`.
